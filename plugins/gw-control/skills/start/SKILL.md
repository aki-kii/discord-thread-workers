---
name: start
description: Discord スレッド中継の GW セッションを起動する。「GW を立てて」「Discord の中継を起動して」「gw start」などのときに使う。すでに動いていれば何もしない。
---

`${CLAUDE_PLUGIN_ROOT}/bin/gw-start` を実行し、**出力をそのまま利用者に見せてください。**

点検・起動・確認はすべてスクリプトの中で完結しています。あなたが判断することは何もありません。

- 事前に状態を調べたり、別のコマンドで確認したりしないこと
- 失敗した場合は、出力に書かれている対処をそのまま伝えること。自分で直そうとしないこと
- 終了コードが 0 以外でも、出力に説明があるのでそれを見せれば足ります
